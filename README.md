# 🎯 IKUN 手速测试 · Accuracy Trainer

一个纯前端的手速 + 准度训练小游戏，单文件 HTML，双击即玩。

随机生成小球，尽可能**快**且**准**地点击它们，实时统计反应速度、命中率、点击精度，并给出综合评分。

## ✨ 特性

- 🎨 视频背景 + 背景音乐，毛玻璃 UI
- 🎮 两大模式自由切换：**普通模式** / **狂暴模式**
- 📊 实时数据面板：反应速度、命中率、精度、连击、综合评分（S/A/B/C/D）
- 🔥 狂暴模式独享 **真爱粉** 难度 —— 出球速度随时间线性递增，越后期越疯狂
- 🔊 内置音乐播放控制（播放/暂停/静音/音量）

## 🎮 玩法

1. 双击 `index.html` 打开
2. 点击「开始游戏」按钮
3. 屏幕上随机出现彩色小球，点击它们
4. **越靠近圆心精度越高**，**越快点中反应分越高**
5. 时间结束后查看综合评分

## 🌗 模式与难度

### 普通模式（默认）
| 难度 | 球大小 | 存活时间 | 生成间隔 | 时长 |
|---|---|---|---|---|
| 简单 | 110 px | 4.0 s | 1.5 s | 30 s |
| 普通 | 65 px | 2.4 s | 0.95 s | 30 s |
| 困难 | 48 px | 1.8 s | 0.7 s | 30 s |
| 疯狂 | 34 px | 1.3 s | 0.5 s | 30 s |

### 狂暴模式
- 切换后**视频背景与背景音乐**同步切换
- 难度选项只保留 **困难 / 疯狂 / 真爱粉**
- 默认难度：困难
- 切到狂暴模式 **2 秒后自动开始**

**真爱粉**（难度递增 · 总时长 120 s）：
| 维度 | 开局 | 收尾 |
|---|---|---|
| 球大小 | 60 px | 20 px |
| 存活 | 1.8 s | 0.45 s |
| 生成间隔 | 1.0 s | 0.12 s |

## 📊 数据指标

- **反应速度**：本次 / 平均 / 最快 / 最慢
- **命中率**：命中 / 总出现球数
- **精度**：点击点到圆心距离换算，越靠近圆心越接近 100%
- **连击**：连续命中不 miss 的次数
- **综合评分**：反应 35% + 精度 35% + 命中率 30% → S / A / B / C / D

## 🚀 运行方式

**本地**：直接双击 `index.html` 即可，无需任何依赖。

**在线**（GitHub Pages）：将仓库设置 → Pages → 选择 `main` 分支根目录 → 保存。

> 浏览器策略：首次打开时音乐可能不会自动播放，点击任意位置或「开始游戏」按钮即可触发。
